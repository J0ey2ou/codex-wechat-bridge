# 鲁滨逊 V0.3.0 交付与使用说明

鲁滨逊把微信自然语言消息交给 Codex 理解，再直接回答或安排对应项目工作。V0.3.0 提供自带 Node 的 Windows 便携 EXE、关闭窗口后持续运行的后台服务、微信主动推送开关，以及通过公开 App Server API 观察桌面项目完成情况的能力。原有微信 iLink、项目会话、OpenAI 登录、记忆和用量证据继续保留。

## 启动和升级

便携版适用于 Windows x64。完整解压 `release/鲁滨逊-Windows-x64.zip`，双击解压目录里的 `鲁滨逊.exe`；本机当前入口为 `release/鲁滨逊/鲁滨逊.exe`。EXE 必须和旁边的 `runtime`、`app` 文件夹一起保留。本轮完整包自带 Node、官方 Codex 和中文字体，无需系统 Node/npm/Python/Codex；仍需 Edge/Chrome 和用户自己的登录。

后续打包会保留旧目录和 ZIP。通过空闲检查、正常退出、数据库及安装目录备份后才能切换。概览页显示实际运行构建编号。本轮原版 R 图标已编译并验证九个尺寸的 EXE 资源；此前原生编译受限记录属于历史状态，最新证据在软件“项目问题记录”。

便携版配置位于 `%LOCALAPPDATA%\Robinson\config.json`。首次在原机器启动时，若发现附近原源码配置，会沿用原数据目录及已有微信绑定；新机器默认使用 `%LOCALAPPDATA%\Robinson\data`，需要完成自己的登录和微信绑定。发行包不包含、复制或迁移账号凭据、原数据库或 `config.local.json`。同机沿用是继续读取原数据目录，不是把凭据打进程序。

源码运行仍需 Node.js 22.13+（推荐 Node 24 LTS）。首次安装执行 `scripts\install.ps1`；已有依赖时：

```powershell
cd D:\codex-wechat
npm run build
# 等当前微信项目任务结束后，再停止旧版服务：
.\scripts\stop.ps1
# 独立窗口入口，也可双击 Robinson.cmd：
npm run app
```

本机没有全局 npm 时：

```powershell
node node_modules/typescript/bin/tsc -p tsconfig.json
node scripts/copy-ui.mjs
node scripts/robinson.mjs
```

启动器核对构建编号，不会把同版本号的旧服务当成新版。EXE 在托盘管理 Node 和 Bridge，关闭页面仍处理微信；托盘菜单可重开或安全退出，存在未完成任务/待发消息时拒绝退出。没有自动设置 Windows 开机自启。浏览器资料在实际数据目录的 `app-browser`，不使用私人浏览器资料。服务只监听 `http://127.0.0.1:3210`；PWA 仍依赖本地服务。

已有数据按 SQLite 迁移版本升级。V0.2 引入的 v3 事务迁移会把原项目、任务、提醒和会话归属当时已绑定用户，保留项目会话 ID；旧库若没有绑定用户，业务数据保留本地归属，不自动分配给新用户。升级前按既有运维流程备份实际数据目录；不要同时运行两个版本访问同一数据目录。

## 微信推送与桌面项目完成

顶部“微信推送”开关和“连接与设置”中的同一设置控制主动通知。关闭后，项目进度、完成通知和待办提醒等主动推送停止，微信发来的问题仍正常回答。再次开启只恢复之后的通知，不补发关闭期间积累的消息；已经提交给微信的消息无法撤回。

后台通过 Codex 公开 App Server API 读取桌面项目会话与完成结果。首次观察建立基线，不补发已有的历史完成记录；后续观察到的新完成结果才可能形成通知。该观察不创建模型轮次，不接管或续跑桌面会话，也不增加模型调用。服务未运行、接口暂不可用或微信连接失效时，不保证立即收到完成消息。

## 软件内连接

1. 打开“连接与设置”，获取微信二维码，扫码并在本机确认绑定。继续使用原有 iLink 流程及 DPAPI 凭证存储。
2. 点击“使用 ChatGPT 登录”，再点击 OpenAI 官方登录链接。密码仅输入官方页面；App Server 托管回调、凭证和刷新。完成后返回 App，状态每 5 秒检查一次。可取消登录或退出；登录切换期间暂停开始新的模型轮次。
3. 回到概览、项目、任务、待办页面操作；日常继续在微信自然表达需求。

登录使用官方 `account/login/start`（`type=chatgpt`）、`account/login/completed`、`account/read`、`account/login/cancel` 和 `account/logout`。只接受 `https://auth.openai.com` 或 `https://chatgpt.com` 返回地址，不保存授权 URL，不读取 `auth.json`，不复制现有 token。此入口连接的是 Codex 的 OpenAI 登录，当前未实现面向任意服务的 OAuth 客户端或其他 AI 提供商。

沿用现有 Codex 环境有利于保留项目与会话；退出也影响共享该环境的 CLI。当前一个运行实例同时绑定一个微信用户，AI 服务账户属于该本机实例，并非每位微信用户单独持有一个 OpenAI 订阅。

官方文档区分 [ChatGPT 订阅认证与 API Key 计费](https://learn.chatgpt.com/docs/auth)。API Key 登录走 OpenAI Platform API 计费；ChatGPT 登录不自动产生 API 额度。另有面向本地应用的 [Sign in with ChatGPT 套餐使用授权](https://developers.openai.com/siwc/token-sharing-open-source)，它需要独立的套餐使用权限，不能仅凭身份登录宣称拥有推理额度。本次采用现有 Codex 官方托管登录路径。协议依据：[App Server 账户接口](https://learn.chatgpt.com/docs/app-server)。

## 个性化和隐私边界

- “个性与记忆”页可查看、新增、编辑、删除记忆，选择自然/温暖/直接语气与简洁/详细/逐步适应，关闭记忆或风格学习，清空记忆和本地对话。
- 微信可以说“记住我喜欢先看结论”“你记住了什么”“忘记我喜欢咖啡这条”“清空我的记忆”。所有读写从绑定身份取得用户 ID，不能在接口传另一个用户 ID 来操作其记录。
- 自动学习只累计当前用户直接提出的有限详略反馈，例如“简短点”“详细一点”。至少 3 次同向反馈且领先相反反馈 2 次时形成偏好；手动设置优先。长期事实仅保存明确要求记住的内容或手动输入，最多 50 条，每条 800 字。不会把转发文字、工具结果或模型猜测自动写成个人事实。
- 每次模型请求注入当前用户偏好与记忆。编辑、删除、关闭后提高记忆版本、重置问答会话，并从近期上下文排除旧版本结果，防止刚删的内容从历史重现。项目执行会话保留原有工作上下文，不自动注入个人长期资料。
- v3 为任务、待办、审批、项目会话和记忆增加归属校验；重新绑定时只显示当前用户的数据。延迟转发收集和重启恢复也检查用户归属。未完成对话/任务期间禁止解绑和账户切换。
- 清空本地对话会删除问答和本地投递记录、去掉接收消息正文，同时保留去重标记。不会删除官方 Codex 会话副本、已有备份、项目文件或任务结果；官方历史需在 Codex 内另行管理。此应用不是对共享 Windows 账户的安全隔离环境。

鲁滨逊可以逐步形成稳定的个性表现和交流习惯，但始终是 AI，不会变成真人，不应以真人身份或虚构生活经历误导使用者。这里的个性化是可审阅的上下文与偏好机制，不是训练了一个新模型。

## 验证记录与升级检查

当前版本的自动化检查、真实微信收发和手动验收，以 `TEST_REPORT.md` 中对应版本及时间的记录为准。便携版可通过 `鲁滨逊.exe --self-test <报告路径>` 检查私有 Node、SQLite、生产依赖和编译模块；该自检不启动微信、不调用模型、不打开窗口，不能代替手机端和界面验收。

V0.2 初次验证曾完成 TypeScript、编译、Mock 服务和 HTTP/API 检查，同时遇到部分 stdio 用例的 `spawn EPERM` 及 Mock 页面浏览器权限限制。这些是旧版执行环境的历史记录，不作为当前版本通过或未通过的结论。

升级检查包括：完整解压后双击 EXE；确认原机器绑定与数据保留；关闭窗口后用微信问答；关闭主动推送时确认问答仍可用；重新开启时确认没有历史补发；观察之后完成的桌面项目；核对记忆、会话和账户用量。新机器的真实登录与扫码由用户在官方页面或手机上完成。
