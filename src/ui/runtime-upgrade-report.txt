鲁滨逊功能与验证说明

独立便携包包含 Node、官方 Codex CLI、生产依赖、中文 PDF 字体和原版 R 图标。后台与 EXE 托管启动，启动时核对构建指纹。更新流程检查未结束任务、备份数据库和旧包后切换。

原线程续接使用官方 thread/resume 与 turn/start，按用户、项目和真实线程绑定；不把 fork 或新线程当作续接。重复请求去重，忙碌排队，重启后不重放不确定的执行。指定模型通过官方目录核验；实际模型未被报告时保持为空。

2026-10-27 增加 Codex 页面及其他入口的只读对话观察。概览与任务页显示项目、真实 ID、最近活动、最近轮次、状态依据及读取时间，无需从微信启动任务。Bridge 未结束任务去重。每 5 秒检查，有限分页和摘要预算，无额外模型调用或微信提醒。

跨客户端状态有边界：独立 App Server 可能将正在其他客户端执行的对话返回为 notLoaded，并把未结束轮次投影为 interrupted。此时显示“有活动 · 运行待确认”，不能认定执行已停止，也不能虚报已确认执行中。只有 active 才计入确定运行数量。错误、断线及过期状态单独标记，重启不复用旧运行态。

新增观察回归覆盖外部双任务、等待、状态投影、完成/失败、断线、去重、隔离、分页、重启和只读边界。本机报告按用户隔离，源码仅含通用说明。实际生效请查看构建编号、desktopActivity 能力标识和成功观察时间。

默认微信回复文字，仅明确要求时生成并发送 PDF。中文分页和本地下载已测试；真实手机接收附件仍需现场确认。对话共用按用户生效的口语风格，无额外润色模型调用。ChatGPT/Codex 套餐与 OpenAI API 计费分别报告，不推测余额。

官方接口依据：https://learn.chatgpt.com/docs/app-server
