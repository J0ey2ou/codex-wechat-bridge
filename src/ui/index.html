后台运行与开机启动

          

            在项目目录运行 scripts\start.ps1 启动后台服务；scripts\stop.ps1
            停止。登录 Windows 后自启可运行
            scripts\enable-autostart.ps1，取消使用
            scripts\disable-autostart.ps1。
          

          

            脚本以当前用户权限运行，不创建管理员服务。电脑睡眠或关机期间不会投递提醒，恢复后补发到期事项。
